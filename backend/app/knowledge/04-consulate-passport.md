The child's passport is issued by the parents' home-country consulate, a foreign mission. No UAE system can reach
it: there is no API, no service-level agreement and no status feed. It typically takes 2 to 8 weeks and it is the
step that fails most often, because nobody tells the parent when it clears and the visa file sits unopened.

LifeLoop never claims a consulate status. It asks the parent for each milestone (appointment booked, application
submitted, passport issued), records the answer with a timestamp as PARENT-REPORTED, and re-plans the residence
visa filing as soon as the parent reports the passport issued. LifeLoop stores only whether the passport number is
available, never the number itself.

Consulate fees vary by country and are not in LifeLoop's sources; the agent does not quote them.
